INNER JOIN vs LEFT JOIN: predict which rows come back

Lesson 0001 · about 20 minutes · Level 1, Recall

Which rows survive

An INNER JOIN keeps only rows with a match in both tables. A LEFT JOIN keeps every row from the left table and fills the right side with NULL when nothing matches.
