INNER JOIN vs LEFT JOIN: predict which rows come back

Lesson 0001 · about 20 minutes · Level 1, Recall

Your win today: given two small tables, you can say which rows each join returns.

Before you read: recall

Which rows survive

An INNER JOIN keeps only rows with a match in both tables. A LEFT JOIN keeps every row from the left table and fills the right side with NULL when nothing matches.1 A WHERE on a right-table column removes the NULL rows again, so a LEFT JOIN with such a filter behaves like an INNER JOIN.2
